# Exercício 02 - Validador de Frases

## 📋 Descrição 
Aplicação destinada para a validação e verificação de frases inseridas pelo usuário por meio da **manipulação de strings** caractere por caractere. Além disso, é visada a prática de lógica condicional e pensamento condicional para a decomposição de problemas em passos simples.

## 📑 Requisitos
- Solicitação para o usuário digitar uma frase, por meio do uso do fgets e limpeza do do `\n`;
- Uso de funções para os seguintes procedimentos:

    1. Contagem total de caracteres;
    2. Contagem de vogais e consoantes;
    3. Contagem de palavras (baseado em espaços);
    4. Verificação se a frase é um palíndromo (ignorando espaços, acentos e diferenciando maiúsculas/minúsculas).

> Observação: para a implementação dos procedimentos citados anteriormente, não devem ser usadas funções prontas, como `strlen` para a contagem de caracteres.
