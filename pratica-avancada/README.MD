Pasta destinada ao versionamento de aplicações desenvolvidas em linguagem C, voltadas para prática individual, aplicando conceitos aprendidos e aprendizado de novas técnicas de modularização.

## 📜 Sobre
Pasta criada a fim da reunião de aplicações desenvolvidas para prática pessoal, abordando casos reais ou usos situacionais para construção dos algoritmos. Os principais objetivos desse projeto de prática profissional são:

- Desenvolvimento do pensamento computacional;
- Aplicação de conceitos de Estruturas de Dados;
- Cumprimento de requisitos de acordo com as regras de negócio;
- Prática da linguagem C;
- Construção de possíveis soluções para situações reais.

O projeto foi divido em cinco exercícios, cobrindo tópicos já estudados e trabalhados anteriormente em outras aplicações, além de novas formas e funções para solução de problemas por meio de algoritmos. É válido ressaltar que os algoritmos foram desenvolvidos pensando na possibilidade de integração com mais funcionalidades internas e externas, por exemplo, adição de bancos de dados.
