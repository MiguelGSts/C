# Projeto Integrando - Cálculo de Compras

Programa desenvolvido em linguagem de alto nível C, destinado para cálculo de valor total de uma compra — atribuindo produtos simples e especiais — e quantas operações foram feitas ao encerramento da aplicação.

## Arquivos
- `main.c` — fluxo principal do programa;
- `operacoes.c` / `operacoes.h` — funções chamadas no fluxo principal(menu, subtotal, qntd. operações, e validação de entrada de dados).
