Aplicações desenvolvidas em prol da resolução de problemas propostos na avaliação bimestral da disciplina de Prática Profissional II (PPII).

## 📋Sobre 
Avaliação individual, realizada no dia 15/09/2026 - 1º Bimestre/2º Semestre. Todos os exercícios seguem como base os requisitos apresentados no arquivo `requisitos-AV.c`.

### 📍Tópicos abordados
- **Estruturas de Repetição**;
- **Laços Condicionais**;
- **Estruturas de Decisão**;
- **Entradas de dados String**;

## 📂Arquivos
- `data-valida`: validação de datas de acordo com o mês e dia informado.
- `jokenpo`: simulação de jogo de 'Pedra, Papel e Tesoura'.
- `placar`: aplicação para identificação de resultado de uma partida de futebol informada pelo usuário.
- `requisitos-AV.c`: requisitos para o desenvolvimento dos códigos.

## 🖱️Como executar
Cada arquivo pode ser executado individualmente.

\`\`\`
gcc data.c -o data
./data
\`\`\`

## 📌Observações
Todas as aplicações foram desenvolvidas de forma individual, sem auxílio de consulta.
